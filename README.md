# 🇵🇪 EPG Perú - Guía de Programación XMLTV para XUI.one

Repositorio automatizado con **GitHub Actions** que genera y actualiza diariamente la guía de programación (**EPG XMLTV**) para los 50 canales peruanos (SD y HD).

## 🔗 Enlaces para tu Panel XUI.one

Una vez subido a tu cuenta de GitHub, usa cualquiera de estos enlaces en **XUI.one ➔ Content ➔ EPG**:

* **XML Directo**:
  ```text
  https://raw.githubusercontent.com/123cuesta123/EPG-PERU/main/epg_peru.xml
  ```
* **XML Comprimido (.gz)**:
  ```text
  https://raw.githubusercontent.com/123cuesta123/EPG-PERU/main/epg_peru.xml.gz
  ```
